# salahegla.com

الموقع الشخصي المهني لـ**صلاح الدين مازن العجلة** — باحث ومستشار اقتصادي، الدوحة.
موقع ثنائي اللغة (عربي/إنجليزي) مبني بـ[Astro](https://astro.build) مع نظام محتوى Markdown.

## البنية

| المسار | المحتوى |
|---|---|
| `src/content/` | المحتوى (مقالات، مشاريع، خدمات) — عربي وإنجليزي |
| `src/content.config.ts` | مخطط الحقول والتحقّق منها |
| `src/pages/[locale]/` | الصفحات (تُولَّد للغتين) |
| `src/components/` | المكوّنات القابلة لإعادة الاستخدام |
| `src/i18n/ui.ts` | نصوص الواجهة بلغتين + بيانات التواصل |
| `src/data/profile.ts` | بيانات السيرة الذاتية الموثّقة |
| `src/styles/` | توكنز التصميم وأنماط القراءة |
| `public/` | الخطوط والصور والملفات القابلة للتنزيل |
| `docs/` | **دليل إضافة المحتوى ودليل النشر — ابدأ من هنا** |

## الأوامر

```bash
npm install
npm run dev      # معاينة محلية
npm run build    # بناء الإنتاج إلى dist/
npm run preview  # معاينة نسخة الإنتاج
```
