# دليل إضافة المحتوى — salahegla.com

هذا الموقع صار يعمل بنظام محتوى منظّم (CMS قائم على ملفات Markdown).
**لن تحتاج بعد اليوم إلى تعديل صفحات HTML لإضافة مقال.**
تُنشئ ملف Markdown واحدًا، فتُبنى صفحة المقال وبطاقته في الأرشيف تلقائيًا.

---

## ١. أين يوضع المحتوى

```
src/content/
├── articles/       ← الأبحاث والمقالات
│   ├── ar/         ← النسخة العربية
│   └── en/         ← النسخة الإنجليزية
├── projects/       ← المشاريع ودراسات الحالة
│   ├── ar/  └── en/
└── services/       ← الخدمات
    ├── ar/  └── en/
```

**القاعدة:** مجلد اللغة هو ما يحدّد لغة الملف. ملف داخل `ar/` عربي، وداخل `en/` إنجليزي.

---

## ٢. إضافة مقال جديد (الخطوات)

**١.** أنشئ ملفًا جديدًا في `src/content/articles/ar/` باسم إنجليزي بدون مسافات، مثل:
`sme-working-capital.md`

**٢.** الصق هذا القالب في أعلى الملف وعدّل القيم:

```yaml
---
title: "عنوان المقال"
subtitle: "عنوان فرعي (اختياري)"
slug: "sme-working-capital"          # يجب أن يطابق اسم الملف
locale: "ar"
translationKey: "sme-working-capital" # نفس القيمة في النسختين العربية والإنجليزية
excerpt: "وصف من سطرين يظهر في بطاقة الأرشيف ونتائج البحث."
category: "sme-finance"
tags: ["رأس المال العامل", "السيولة"]
contentType: "article"
status: "published"
publishDate: 2026-08-15
featured: false
relatedServices: ["financial-analysis"]
---
```

**٣.** اكتب نصّ المقال تحت السطر `---` بلغة Markdown العادية.

**٤.** احفظ الملف وارفعه (انظر قسم النشر). ستظهر الصفحة على:
`salahegla.com/ar/articles/sme-working-capital`

---

## ٣. القيم المسموحة (لا تكتب قيمة خارجها وإلا توقّف البناء)

| الحقل | القيم المسموحة |
|---|---|
| `category` | `economics-policy` · `sme-finance` · `financial-credit-analysis` · `feasibility-investment` · `development-gulf` · `energy-markets` |
| `contentType` | `article` · `research-paper` · `working-paper` · `policy-brief` · `economic-analysis` · `guide` · `case-study` |
| `status` | `published` (منشور بصفحة) · `draft` (لا يظهر إطلاقًا) · `coming-soon` (يظهر في الأرشيف بلا رابط قراءة) · `archived` |
| `locale` | `ar` · `en` |

**حقول اختيارية مفيدة:**

| الحقل | الاستخدام |
|---|---|
| `peerReviewed: true` | يضيف شارة «محكَّم ومنشور» |
| `publishedIn: "مجلة عُمران — العدد 53"` | اسم الدورية أو الجهة الناشرة |
| `externalUrl: "https://..."` | إذا كان النصّ الكامل منشورًا في موقع آخر |
| `pdfUrl: "/files/paper.pdf"` | يضيف زر تحميل PDF (ضع الملف في `public/files/`) |
| `updatedDate: 2026-09-01` | يعرض تاريخ آخر تحديث |
| `references: ["مرجع أول", "مرجع ثانٍ"]` | قائمة مراجع في نهاية المقال |

## ٤. النسخة الإنجليزية من نفس المقال

أنشئ ملفًا بنفس الاسم في `src/content/articles/en/`، وغيّر فقط:

```yaml
locale: "en"
translationKey: "sme-working-capital"   # ← نفس القيمة تمامًا
```

`translationKey` هو ما يربط النسختين. عند تطابقه، يعمل زرّ تبديل اللغة بين المقالين مباشرة.
**وإن لم توجد نسخة إنجليزية، فزرّ اللغة ينقل الزائر إلى الصفحة الرئيسية الإنجليزية بدل صفحة مفقودة.**

---

## ٥. ماذا يدعم Markdown هنا

عناوين (`##`, `###`) · فقرات · **عريض** · *مائل* · قوائم مرقّمة ونقطية · اقتباسات (`>`)
· روابط · صور · جداول · فواصل (`---`) · حواشٍ · شفرة برمجية.

**تلقائيًا يُضاف:** فهرس محتويات المقال (عند وجود 3 عناوين فأكثر)، ورابط لكل عنوان،
وحساب مدة القراءة، **وتغليف الجداول بحاوية تمرير حتى لا تكسر الشاشات الصغيرة**.

---

## ٦. إضافة مشروع

نفس الطريقة في `src/content/projects/ar/`. الحقول الأساسية:
`title, slug, locale, translationKey, summary, sector, projectType, engagement, status, question, methodology[], scope[], tools[], deliverables[], value`

قيم `engagement` المسموحة: `analytical-framework` · `methodological-model` · `research-concept` · `illustrative-case-study`.

> **مهم:** هذه القيم مقصودة. لا تصف عملًا بأنه ارتباط فعلي مع عميل ما لم يكن موثّقًا ومصرّحًا بنشره.

---

## ٧. تعديل خدمة

الخدمات في `src/content/services/ar/` و`en/`. عدّل الملف مباشرة — الحقول واضحة بالاسم
(`audience, problems, scope, deliverables, methodology, inputs, faq`).

## ٨. النشر

### الطريقة الموصى بها: GitHub + بناء تلقائي

بعد ربط المستودع بـNetlify مرّة واحدة (انظر `docs/التشغيل-والنشر.md`)، تصبح إضافة مقال هكذا:

1. افتح مستودعك على GitHub.
2. `src/content/articles/ar/` ← **Add file** ← **Create new file**.
3. الصق المحتوى واضغط **Commit**.
4. Netlify يبني وينشر تلقائيًا خلال دقيقة تقريبًا. **لا رفع ملفات ولا سحب مجلدات.**

---

## ٩. قاعدة ثابتة في هذا الموقع

لا تُنشر أرقام أو مراجع أو نتائج غير قابلة للتحقّق. وإذا كان العمل غير مكتمل،
استخدم `status: "coming-soon"` — فيظهر في الأرشيف بوضوح أنه قيد الإعداد وبلا رابط قراءة،
بدل أن يوهم الزائر بوجود مقال ثم يوصله إلى نموذج التواصل.
